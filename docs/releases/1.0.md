The first desktop release packages the geometry, algebra, CAS, spreadsheet
and construction views. It loads scripts and supported `.ggb` constructions
and saves `.ggb` files. The default EUPL-1.2 edition uses the kernel CAS.
When included, the GPL-3.0-or-later edition uses Giac 70507 for supported CAS
operations. The Giac edition on macOS uses the Intel x86_64 library because
70507's Arm library violates the Apple ARM64 ABI. The Intel library ships
unsigned. Signing would change its pinned bytes, so the macOS Giac
edition is unsigned and un-notarized.
